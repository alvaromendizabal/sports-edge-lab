Spread probabilities and ATS records

Winning the game is a different question.

A cover probability describes one quoted line. An against-the-spread record describes prior settled comparisons. This example shows both with invented inputs.

Change the line. Keep the model fixed.

Invented full-game home-minus-away margin distribution, including overtime. The home win probability stays 75%.

Cover when home margin + home spread is positive; push at zero; fail to cover when negative. Push probability is separate, so the away cover probability need not equal one minus home cover probability.

These are invented probability masses, not a fitted NCAA model or a live price. A real probability needs a validated margin distribution, exact teams, gender, line, horizon, source version, information clocks and settlement scope. A point margin or winner probability alone cannot supply it.

The invented inputs include one result with an unknown availability clock. It remains excluded; the missing clock is never replaced with capture time. Only earlier completed games known before the target cutoff can enter a team’s prior record.

The record is descriptive. Its win rate is not the next game’s cover probability. Home and away orientation, provider, US/international product, horizon, evidence tier, pushes and gaps remain separate. Each exact quoted line and its availability must be retained.
