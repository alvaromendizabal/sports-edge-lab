Selection requires a future/remaining game with a verified line and a complete, consistent distribution. Noninteger spreads require a zero push probability.

Explicit `win_away` is never replaced by `1 - win_home`. Complementing home probability is allowed only for a declared binary target or absent/zero tie probability. Metric values remain the saved full-precision aggregates; display rounding does not regrade them.
