Population completeness comes before ranking

Same-game model comparisons

Each table names its game population, target and evidence class. A full-population comparison can support a rank only when its official denominator, declared model roster and eligible game coverage are qualified. A shared intersection is a secondary, unranked descriptive view.

The earlier 50%/35%/15% weighting is retained only as a descriptive sensitivity policy. Champion selection uses the 2024–25 and 2025–26 validation populations; 2026–27 stays the already-exposed test/monitoring population and is not used for tuning, selection or automatic promotion.

Secondary shared-intersection comparisons · unranked

These tables keep the declared target-specific model roster and use only games with evidence for every member. Their reduced game sets remain descriptive even when every displayed row uses the same cohort hash.

Individual model observations · separate subsets, unranked

These are each model’s own observed subsets, split by season, target and evidence class. Their game sets can differ, so these rows are not a same-game leaderboard. The model filter above also applies here. The population audit supplies point estimates; it does not establish significance or an uncertainty-adjusted winner.

Reading the metrics and evidence classes

Winner accuracy describes correct winner selections. Log loss and Brier score measure probability quality; lower values are better. Margin and total MAE/RMSE measure error in points. Missing scores remain unavailable, rather than becoming zero.

Original-issued predictions, time-valid replay, later-fitted reconstruction and missing evidence are kept distinct. A later fit cannot receive credit as an earlier issued forecast. Winner, spread, margin thresholds and totals are separate targets.
