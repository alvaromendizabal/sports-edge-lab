## Why startup failed again

The recorded exception was `B055_CURRENT_B054_TERMINAL_RETURN_FILE_REQUIRED`. The native recovery configuration required a legacy local return archive and failed before reaching stage-journal consumption. The earlier authentic three-stage adoption check had called the journal recovery candidates directly. It had verified authentic prior outputs, but it had not traversed the native startup boundary that failed here.

All three invocations reused the exact 1,430-case source/runtime-qualified startup receipt. The problem was the missing native integration coverage, rather than evidence that those cases or already completed optimizations needed to be rerun. R33 preparation must exercise the actual startup and historical-return discovery path in fresh processes while stopping before research dispatch.
