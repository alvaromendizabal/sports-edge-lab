# FBS publication boundary · V5 methodology

This FBS-only clarification preserves the repository's [publication boundary](../PUBLICATION_BOUNDARY.md) and every earlier dated public report. It does not expand another sport's publication scope.

## Four roles, separate evidence

The public review distinguishes a historical foundation, a current-regime specialist, a market-only reference and a market-residual model. An implemented or prepared capability is not an executed study, a forecast issue or a promoted model. New-policy forward monitoring begins after registration and a genuine timestamped issue; previously inspected outcomes remain exposed development evidence.

Sanitized aggregate metrics may show each family's own cohort and an independently authenticated matched-control cohort. The event, target, horizon, orientation and source eligibility must match before a pair is presented as comparable. Full-universe model results remain separate from a provider-qualified subset. Missing or unsupported reference products are not zero probabilities.

## What this update permits

- Owner-authenticated aggregate evaluations of unchanged saved forecasts, with dates, denominators, cohort hashes, evidence classes and explicit limitations.
- Official fixture and result metadata, source-clock and exact-association counts, dated forecast availability and refresh-gap reasons.
- Generic descriptions of adaptive forecasting, source-qualified reference comparisons, rollback and calibration gates.
- Credential-free invented tests and source-accounting demonstrations.

The existing narrow authorization for earlier FBS rounded game displays remains historical evidence. New private unissued candidate grids, exact adaptive recipes, feature columns or transforms, parameters, weights, state bodies, cloud identifiers and raw licensed provider data remain excluded. A full private standing prompt or owner handoff is not a public model card.

## Claims and delivery

Current-season specialization requires admissible forward evidence; it is not a license to tune on known outcomes and call the resulting replay prospective. A price association does not establish a fair-probability benchmark or a calibrated exact-line outcome. Independent winner, margin and total heads do not automatically form a coherent joint score distribution.

The public product remains forecasting research, without action-oriented financial controls or recommendations. Every release distinguishes source observation, original result availability, saved forecast computation, evaluation and deployment clocks. Publication does not refresh data, retrain models or create an issue. Original numerical assets and README history remain byte-preserved.
