EVIDENCE BEFORE INTERPRETATION

How to read this report

Original issued

A saved pregame issue

The original delivery, fitted-model and feature clocks are preserved. “Issued future outlook” means the game was still ahead at the assessment cutoff; it is not an updated forecast.

Later reconstruction

A retrospective comparison

A saved research output may have been created after kickoff, or its historical source possession or model ancestry may be unproved. It can support a labeled descriptive comparison, not prospective performance.

Chronology-valid replay

A separately qualified class

A replay requires valid training, feature and label cutoffs. It keeps its replay label even when chronology is proved. No reconstruction is silently moved into this category.

Unknown / missing

An explicit information gap

A known final without score bytes, an elapsed kickoff without a later result observation, and a missing forecast stay distinct. Missing values are never replaced with zeros.

Scope of the publication

Selected rounded family leaders and the saved issued baseline are public analytical outputs. Full private candidate grids remain outside this report.

Leaderboard values use the full-precision private evidence calculations; displayed game probabilities and point predictions are rounded only for publication. No headline metric is recomputed from rounded display values.

All-games inventories and matched-source comparisons use separate denominators. A composite saved market reference is never relabeled DraftKings, Kalshi or Polymarket. Fees, vig and contract semantics must be established before a named-source edge is claimed.

The assessment made no new model fits. No qualified full-current-season champion or selection-adjusted 95% confirmation is claimed. A new report does not constitute a model improvement, a source refresh or an executable betting instruction.
